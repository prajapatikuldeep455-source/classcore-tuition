# Changelog

All notable changes to ClassCore will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-09-03

### Added
- **New Dashboard** - Redesigned with enhanced analytics and real-time metrics
- **Advanced Reporting** - Custom report builder with multiple export formats
- **Batch Management** - Improved batch creation with template support
- **Financial Analytics** - Revenue forecasting and expense categorization
- **Parent Portal** - Web interface for parents to view performance
- **Mobile Responsive** - Better support for tablet and mobile viewing
- **Automated Backups** - Daily cloud backups with point-in-time recovery
- **Multi-language Support** - English, Hindi, and Gujarati support
- **Dark Mode** - Modern dark theme for reduced eye strain
- **API Documentation** - REST API for third-party integrations

### Improved
- Database performance with optimized queries
- UI/UX with modern design principles
- Security with enhanced encryption
- Batch operations for faster data entry
- Report generation speed (50% faster)
- Export functionality with more formats (PDF, Excel, CSV)

### Fixed
- Memory leak in attendance marking
- Firebase sync conflicts
- PDF generation timeout issues
- Session management bugs
- Decimal rounding errors in calculations

### Changed
- Minimum Node.js version: 14.0.0
- Updated dependencies to latest versions
- Modified fee calculation algorithm

### Removed
- Legacy XML export format
- Internet Explorer compatibility
- Old dashboard themes

### Security
- Updated authentication mechanism
- Implemented JWT tokens
- Enhanced data encryption

## How to Update

To update to the latest version:

1. Download the latest installer from [Releases](https://github.com/prajapatikuldeep455-source/classcore-tuition/releases)
2. Run the installer
3. Your existing data will be automatically preserved
